# 任务执行等级判定与复核

执行者按原交办、有效文档版本、验收行为、实际使用方和错误后果判断影响。工作量单独估算。同项多种行为取最高等级，并验证各行为需要的检查。

| 等级 | 可核实的依据 | 必测行为 |
| --- | --- | --- |
| R0 | 说明、注释，或稳定标识和业务含义均相同的展示措辞 | 核对内容和受影响标签、列表、详情 |
| R1 | 局部布局、分页选项、简单交互 | 受影响状态、操作、数据展示与视口 |
| R2 | 单业务域的功能 | 正常、边界和失败路径 |
| R3 | 多个真实使用方的契约、共享事件或构建约定 | 契约及各使用方的兼容性 |
| R4 | 授权隔离、价格库存、删除迁移、验证与交付放行的变化 | 针对拒绝、并发、重复执行、历史数据、恢复或错误放行的完整受影响链路 |

## 固定的验收预期

| 样本 | 整项或本轮 | 对应覆盖 |
| --- | --- | --- |
| 001 入库文案 | 整项 R0 | 入库标签和操作日志列表、详情。加入同步文案的测试后仍为 R0 |
| 003 同店选品 | 整项 R4，单轮空清单背景 R1 | 整项验证同店两人并发和跨店隔离。背景验证空态与视口 |
| 004 操作保护 | 整项 R4 | 删除前置检查、重复提交与验证控制 |
| 005 款项配置分页 | 整项 R1 | 10、20、50 条选项、翻页和实际记录。加入用例与模拟数据后仍为 R1 |

另用独立报表的文案、布局、共用分页契约、库存写入和拒绝断言样本，对照实际等级、必测及无关检查。已有证据按用例范围、相关输入和环境复用。
