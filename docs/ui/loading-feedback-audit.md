# 三端加载反馈核对记录

任务 008 按实际事件检查等待位置。路由、配件别名、订单子页及历史跳转对照[项目逐页清单](operation-feedback-audit.md)。下表按共用实现归并，测试覆盖包括公共组件与代表性业务路径。

| 页面或共用入口 | 操作执行中的反馈 | 数据读取中的反馈 |
| --- | --- | --- |
| 门店分类、商品分类 | 新增、编辑、启停、删除对应的确认按钮 | 分类树和排序结果在表格显示；本地筛选直接更新 |
| 属性、属性值、分类属性模板、成品工艺 | 保存、删除与草稿操作使用对应提交按钮 | 属性列表、可选属性与属性值在内容区等待 |
| 大板品种、产地、纹理、色系、等级 | 表单与确认按钮；别名删除定位到该行 | 表格、色系类别及纹理别名读取 |
| 供应商、供货类型、租户、门店、门店等级 | 表单、状态和风险确认按钮 | 管理表格、打开供应商表单前的选项读取 |
| 运营端与供应链端的成品、配件、大板 | 表单保存、下架原因、确认操作；有远程预检的行入口单独计时 | 商品列表、打开编辑资料、详情抽屉、操作日志 |
| 门店成品、配件、商品编辑、门店和平台价格配置 | 商品状态、价格和编辑提交使用当前按钮 | 商品列表、详情、价格配置列表 |
| 门店客户 | 保存档案、跟进及风险确认 | 列表、档案选项、详情及附件读取 |
| 门店选品中心 | 加入、移除和清单提交按操作定位 | 首屏、翻页和清单按区域等待。商品详情在被点击的商品卡或清单行提示，资料返回后打开抽屉 |
| 门店订单的销售、履约和设置 | 编辑及业务确认框；款项名称维护 | 读取门店范围和款项选项；本机订单数据直接展示 |
| 员工、角色、终端功能分配 | 邀请、维护、权限保存的发起按钮 | 员工与角色列表、终端权限矩阵 |
| 登录、邀请、身份切换及退出 | 登录、验证码、提交及当前身份入口 | 打开邀请链接在邀请内容区等待 |
| 工作台、历史跳转 | 工作台共用顶栏 | 工作台自身的静态统计与菜单直接展示；重定向由目标页处理 |

## 验证入口

- 公共计时与并发测试在 `src/composables/useDelayedLoading.test.ts`，检查 199 / 200 毫秒边界、请求被替换、不同记录并发、关闭、重试及卸载。
- 门店分类端到端测试在 `tests/e2e/store-category-management.spec.ts`，用隔离接口响应检查快速删除、慢速停用、连点和按钮宽度，以及写入结束后独立的列表刷新。
- `npm run test:source-guards` 对运行时组件逐个核验脚本与事件登记。已有业务约束、原始指纹及拒绝反例继续通过项目原有检查验证。
