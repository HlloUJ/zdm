# 已批准的视觉迁移范围

## 范围和实施

- 范围：现有51个页面/页面组件，以及公共基座、权限矩阵和页面专用共享CSS；按真实路由跨运营、供应链和门店覆盖。
- 业务契约：`visual-refactor.json`。现有API服务、路由、状态管理、字段、文案、模型、事件和模板条件不得变化；此前明确批准的自动折叠、菜单悬停修复，以及本轮默认弹窗宽度和按钮展示主题以精确补丁登记，校验时还原后核对原业务快照，不覆盖原始哈希。
- 公共层：官方字体/平滑、列表容器、分页间距、Tab默认值、菜单默认组件样式、表格列对齐和内边距；保留拖拽点击区及视口遮罩保护。
- 基础模块：租户/门店、供应商、角色员工、功能分配、基础数据、分类/属性/模板、加价配置和工艺，标准查询/按钮/列表区迁移。
- 商品模块：运营/供应链/门店成品现货，大板双端、售价配置，保留复杂编辑、归属、权限、批量、上下架、失效及日志交互。
- 其余页面：登录/邀请/仪表盘沿用原内容与业务，去除非官方通用颜色/字号/卡片覆盖。客户页沿用已确认样板。已使用官方变量的历史对照、媒体比例与矩阵布局保留。
